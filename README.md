Shopping App Project

Overview

This project is a simple shopping application implemented in Python. It provides functionalities for both users and administrators, allowing users to browse products, manage their shopping cart, and proceed to checkout, while administrators can manage the product catalog.

Features

User Role:

Login authentication for users

View available products

Add/remove items from the shopping cart

Proceed to checkout

Admin Role:

Login authentication for administrators

Manage the product catalog (add/remove/update products)

Installation

Clone the repository or download the project files.

Ensure you have Python installed (version 3.x recommended).

Install required dependencies if applicable (e.g., pip install -r requirements.txt).

Run the Python script using:

python main.py

Usage

Run the application.

Choose the appropriate role (User/Admin) and log in using demo credentials.

Interact with the shopping catalog and perform actions based on your role.

Files

Project1_PGE1.ipynb: Jupyter Notebook containing the main implementation.

main.py: Script for running the application.

requirements.txt: List of dependencies (if any).
